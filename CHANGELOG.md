# Changelog

The changelog is the Releases page of this repository: every release has its
notes there, generated from the commit messages with
[git-cliff](https://git-cliff.org) when the release is published (see
[docs/contributing.md](docs/contributing.md#releasing)).

This file only points there, so there is nothing to keep in sync by hand.
The notes of `v0.1.0` were written by hand
([`.github/release-notes/v0.1.0.md`](.github/release-notes/v0.1.0.md)),
because the history is squashed before the project goes public and so has no
commits to generate them from.
